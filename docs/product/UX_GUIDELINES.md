# UX 指南

- 玩家可见文本以简体中文为主，短句、清晰状态、减少技术词汇。
- 桌面、平板、手机共享统一信息架构；重点检查 375px、768px、1440px。
- 桌面使用顶部导航，手机使用固定底部导航，关键入口始终可达。
- 游戏卡片统一展示名称、简介、分类、玩家模式和文字状态。
- 空状态说明原因并给出合理下一步，不伪造内容。
- 不采用金币、筹码、下注、大红大金或赌场式表达。
- “即将开放”与“敬请期待”必须真实；没有游戏时禁止“开始游戏”。
- 按钮、链接和输入提供键盘 focus；颜色不是状态的唯一表达。
- 动效应短、可中断，并尊重 `prefers-reduced-motion`。
